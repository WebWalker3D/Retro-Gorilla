# Retro Gorilla

A 3D homage to the classic QBasic banana-throwing gorilla duel. Two gorillas stand on a city skyline and take turns lobbing explosive bananas at each other. You set the angle and power and allow for the wind. The buildings get blown apart as you go.

**Status:** in development.

## Build & run

```bash
npm install
npm run dev      # dev server
npm test         # sim tests
npm run build    # production build in dist/
```
